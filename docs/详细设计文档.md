## 1. 设计原则与约束

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **分层解耦** | 设备层、能力层、编排层、应用层各自独立演进，层间通过定义清晰的接口通信 |
| **协议抽象** | 机器人、相机、PLC 等设备通过统一的驱动接口适配，上层无需感知具体品牌/协议 |
| **状态机驱动** | 工位控制核心基于有限状态机（FSM），所有状态转换可追溯、可测试 |
| **失败闭环** | 从失败检测 → 重试/降级 → 样本采集 → 模型迭代，形成自动化闭环 |
| **可观测优先** | 每个模块暴露指标（metrics）、日志（logs）、链路（traces）三类观测数据 |

### 1.2 技术约束

- 边缘端实时控制模块使用 **C++17 + Qt6**，与现有 `WorkcellController` 保持一致
- 模块间通信优先使用 **gRPC**（跨进程）和 **Qt Signal/Slot**（进程内）
- 推理引擎使用 **ONNX Runtime**，可选 TensorRT 加速
- 平台端后端使用 **Go + PostgreSQL**
- 前端使用 **Vue3 + TypeScript + Three.js**（3D 点云可视化）

### 3.1 设备层（Device Layer）

#### 3.1.1 设备驱动抽象接口

所有设备类型实现统一的基类接口，上层通过工厂模式获取具体驱动实例。

```cpp
// src/device/idevicedriver.h
class IDeviceDriver {
public:
    enum class DeviceStatus { Disconnected, Connected, Ready, Error };

    virtual ~IDeviceDriver() = default;
    virtual bool connect(const QVariantMap& config) = 0;
    virtual void disconnect() = 0;
    virtual DeviceStatus status() const = 0;
    virtual QString deviceId() const = 0;
    virtual QString deviceType() const = 0;  // "Camera", "Robot", "PLC", "Gripper"
};
```

### 3.2 能力层（Intelligence Core）

#### 3.2.1 3D 视觉流水线（VisionPipeline）

```cpp
// src/vision/visionpipeline.h

struct DetectionResult {

    QVector<DetectionResult> execute();

    // 单步调试接口
    PointCloud captureAndPreprocess();
    QVector<DetectionResult> detect(const PointCloud& cloud);

signals:
    void pipelineStarted();
    void pipelineFinished(int objectCount);
    void pipelineError(const QString& error);

private:
    ICameraDriver* m_camera = nullptr;
    QString m_modelPath;
    QVariantMap m_preprocessConfig;
    // ONNX Runtime session 管理
    // Ort::Session m_session;

```

**流水线内部阶段：**

```text
采集(Capture) → 点云预处理(Preprocess) → 分割/检测(Detection)
    → 6D位姿估计(PoseEstimation) → 结果过滤与排序(PostProcess)
```

每个阶段可独立替换算法实现（策略模式）。

#### 3.2.2 抓取规划器（GraspPlanner）

```cpp
// src/planning/graspplanner.h

struct GraspCandidate {
    CartesianPose approachPose;   // 接近位姿
    CartesianPose graspPose;      // 抓取位姿
    CartesianPose retreatPose;    // 撤退位姿
    double score;                 // 抓取评分 [0, 1]
    QString gripperType;          // 匹配的夹具类型
};

class GraspPlanner {
public:
    struct Config {
        double minScore = 0.6;          // 最低可接受评分
        int maxCandidates = 5;          // 最大候选数
        bool enableCollisionCheck = true;
        QVector<QVector3D> obstacles;   // 障碍物点云
    };

    void setConfig(const Config& config);

    // 输入检测结果，输出排序后的抓取候选
    QVector<GraspCandidate> plan(const DetectionResult& target,
                                 const PointCloud& sceneCloud);

    // 碰撞检测
    bool checkCollision(const GraspCandidate& candidate,
                        const PointCloud& sceneCloud);
};
```

#### 3.3.3 异常恢复管理器（RecoveryManager）

```cpp
// src/orchestration/recoverymanager.h

struct RecoveryStrategy {
    QString errorCode;
    enum Action { Retry, SkipObject, DegradeSpeed, SwitchGripper, Alert, EStop };
    QVector<Action> actionSequence;  // 按顺序尝试
    int maxRetries;
};

class RecoveryManager : public QObject {
    Q_OBJECT
public:
    void registerStrategy(const RecoveryStrategy& strategy);

    // 根据错误码查找恢复策略并执行
    bool handleError(const QString& errorCode, WorkcellController* controller);

    // 记录失败样本（用于数据闭环）
    void captureFailureSample(const QString& errorCode,
                              const PointCloud& sceneData,
                              const DetectionResult& failedTarget);

signals:
    void recoveryAttempted(const QString& errorCode, const QString& action, bool success);
    void failureSampleCaptured(const QString& samplePath);

private:
    QMap<QString, RecoveryStrategy> m_strategies;
};
```

**预定义恢复策略：**

| 错误码 | 含义 | 恢复序列 |
|--------|------|---------|
| `GraspFailed` | 抓取失败/空抓 | Retry(3次) → SkipObject → Alert |
| `CollisionDetected` | 碰撞检测触发 | DegradeSpeed → Retry → EStop |
| `VisionTimeout` | 视觉超时 | Retry(2次) → Alert |
| `NoObject` | 场景无目标 | Wait(PLC信号) → Retry |
| `RobotCommLost` | 机器人通信断开 | Retry(5次, 2s间隔) → EStop |

### 4.2 消息格式（gRPC Proto）

```protobuf
// 边缘端 → 平台端 上报
message StationReport {
    string station_id = 1;
    string state = 2;           // "Idle", "Running", "Degraded", "Fault", "Stopped"
    int32 total_attempts = 3;
    int32 success_count = 4;
    int32 failure_count = 5;
    double success_rate = 6;
    int32 consecutive_failures = 7;
    double current_cycle_time = 8;
    google.protobuf.Timestamp timestamp = 9;
}

// 平台端 → 边缘端 控制
message StationCommand {
    string station_id = 1;
    enum CommandType {
        START = 0;
        STOP = 1;
        EMERGENCY_STOP = 2;
        LOAD_RECIPE = 3;
        LOAD_WORKFLOW = 4;
    }
    CommandType command = 2;
    bytes payload = 3;  // JSON encoded 参数
}
```

## 6. 接口定义

### 6.1 边缘端模块间 gRPC 服务

```protobuf
// vision_service.proto
service VisionService {
    rpc Capture(CaptureRequest) returns (CaptureResponse);
    rpc Detect(DetectRequest) returns (DetectResponse);
    rpc GetPointCloud(Empty) returns (PointCloudData);

// planning_service.proto
service PlanningService {
    rpc PlanGrasp(GraspRequest) returns (GraspResponse);
    rpc PlanTrajectory(TrajectoryRequest) returns (TrajectoryResponse);
    rpc ValidateTrajectory(TrajectoryPlan) returns (ValidationResult);

// workcell_service.proto
service WorkcellService {
    rpc StartTask(StartTaskRequest) returns (StatusResponse);
    rpc StopTask(StopTaskRequest) returns (StatusResponse);
    rpc EmergencyStop(Empty) returns (StatusResponse);
    rpc GetState(Empty) returns (StateResponse);
```

## 9. 测试策略

### 9.1 测试金字塔

```text
                 ┌─────────┐
                 │ E2E 测试 │   ← 全链路仿真（视觉→规划→执行→统计）
                ┌┴─────────┴┐
                │  集成测试   │   ← 模块间通信、gRPC 接口
               ┌┴───────────┴┐
               │   单元测试    │   ← 各模块独立逻辑（现有 Qt Test 框架）
              └───────────────┘
```

### 9.2 测试覆盖目标

| 层次 | 覆盖内容 | 框架 | 目标覆盖率 |
|------|---------|------|-----------|
| 单元测试 | 状态机、规划算法、恢复策略 | Qt Test | ≥ 85% |
| 集成测试 | 设备驱动 ↔ 控制器、视觉 ↔ 规划 | Qt Test + gRPC mock | ≥ 70% |
| E2E 测试 | 完整抓取循环（使用模拟器） | Python + pytest | 关键路径 100% |
| 性能测试 | 推理延迟、循环节拍 | 自定义 benchmark | 达标即可 |
